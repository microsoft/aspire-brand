# Aspire developer icons

These official derivatives of the Aspire icon are provided for developer-tool use. They complement, rather than replace, the general-purpose [Aspire logos](..) and [brand guidance](../../README.md).

| Variant | Asset | Intended use |
| --- | --- | --- |
| Original | [aspire-original.svg](aspire-original.svg) | Full-color Aspire icon. |
| Line | [aspire-line.svg](aspire-line.svg) | Outline-style icon expressed as filled paths. |
| Plain | [aspire-plain.svg](aspire-plain.svg) | Monochrome icon with a rounded enclosing outer edge and widened negative-space interior seams. |

All three optimized SVGs use a `0 0 128 128` viewBox. The line and plain variants use a single filled path, with no strokes. These files reproduce the approved assets from [devicons/devicon#2762](https://github.com/devicons/devicon/pull/2762) at commit [`a2959500f687ea51ab0f8b17cbbd907c8d443325`](https://github.com/devicons/devicon/commit/a2959500f687ea51ab0f8b17cbbd907c8d443325) without redesign.

This is a narrow exception to the general guidance against recoloring, outlining, or reshaping the logo. It applies to the provided developer-icon variants and the adaptations described above, not to arbitrary redesigns or other brand assets. General brand guidance continues to apply elsewhere.
